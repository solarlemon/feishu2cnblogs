# 飞书文档字体助手

一个 Tampermonkey / 油猴脚本，用于调整网页版飞书文档的**字体**和**字号**。

![Tampermonkey](https://img.shields.io/badge/Tampermonkey-✓-black) ![Feishu](https://img.shields.io/badge/飞书文档-✓-3370ff)

## 功能

- 右下角浮动按钮，点开即用，不遮挡正文。
- 字体：系统默认、微软雅黑、苹方、思源黑体/宋体、宋体、黑体、楷体、仿宋、霞鹜文楷、Times New Roman 等，也可输入自定义字体。
- 字号：12–64px 预设，或自定义 8–96px。
- **应用到全文**：以正文为基准整体缩放，标题按原比例一起变化，不会把标题压成正文大小。
- **应用到选区**：只改选中的文字，精确到字，支持跨段落选择。
- 支持清除选区样式、全部重置、新文档自动应用。
- 适配飞书虚拟滚动：滚动后新渲染出来的段落会自动使用整篇字体设置。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）浏览器扩展。
2. 打开 Tampermonkey 管理面板 → **添加新脚本**。
3. 用 [`feishu-font.user.js`](./feishu-font.user.js) 的全部内容替换编辑器里的模板。
4. `Ctrl + S` 保存。
5. 打开或刷新飞书文档，右下角出现 **Aa** 按钮即可使用。

支持域名：

- `*.feishu.cn` / `feishu.cn`
- `*.larksuite.com` / `larksuite.com`
- `*.larkoffice.com` / `larkoffice.com`

支持页面路径：`/docx/`、`/wiki/`、`/docs/`。

## 使用

### 整篇调整

1. 点右下角 **Aa**。
2. 选择字体、字号。
3. 点 **应用到全文**。

字号会以当前正文的实际字号为基准缩放。例如正文 16px，选择 20px：

- 正文：16px → 20px
- 二级标题：22px → 27.5px
- 文档标题：34px → 42.5px

### 只改选中文字

1. 在文档中选中一段文字。
2. 打开 **Aa** 面板。
3. 选择字体或字号，点 **应用到选区**。

选区的字号是**绝对像素值**，不会跟随全文缩放比例。按钮点击不会抢走编辑器的选区，面板会自动记住最后一次有效选区。

### 恢复

- **清除选区样式**：只移除选区样式，保留整篇设置。
- **全部重置**：恢复飞书默认字体、字号，并清除所有选区样式。

### 自动应用

勾选 **新文档自动应用** 后，下次打开文档会自动套用上次“应用到全文”的字体和字号。设置保存在 Tampermonkey 的脚本存储里，不会上传。

## 重要说明

### 只改变本机显示

脚本通过修改页面 CSS 和 DOM 来改变显示效果，**不会写入飞书云端文档，不会同步给协作方，也不会改变导出文件**。它适合：

- 阅读长文档时换成更舒服的字体/字号；
- 演示、截图前临时调整；
- 在共享文档上按自己的习惯阅读。

如果你需要真正修改文档内容并同步给其他人，应使用飞书自带的字体/字号工具，或通过飞书开放接口写入。

### 选区样式的稳定性

飞书正文由 Slate 编辑器渲染。选区样式是在浏览器 DOM 里给文字加 `<span>` 实现的：

- 在只读/公开文档里通常很稳定；
- 在可编辑文档里，继续输入、切换段落或飞书重新渲染时，样式可能被还原，重新应用即可；
- 脚本不会修改文字内容，清除样式后文字保持完整。

### 字体是否生效取决于本机

字体列表只是 CSS `font-family` 候选。**只有本机安装了对应字体才会真正显示**，否则会回退到候选列表里的下一个字体。例如没有安装“霞鹜文楷”时，会回退到楷体/宋体。

### 选择器兼容性

脚本基于飞书文档当前的结构：

```text
.bear-web-x-container
  .docx-text-block / .docx-heading2-block / ...
    .ace-line
      span[data-string="true"]
```

飞书改版后如果类名变化，整篇样式可能失效。届时更新脚本里的 `DOC_ROOT_SELECTORS` 和 `.ace-line` 选择器即可。

## 已知限制

- 仅支持网页版飞书文档，不支持飞书桌面客户端的独立窗口、移动端 App。
- 飞书虚拟滚动会回收屏幕外的段落，屏幕外已加的选区样式不会保留；滚回来时需要重新应用。
- 代码块会保持等宽字体，不跟随正文的宋体/楷体设置，避免代码排版变形。
- 如果个别文字在飞书里单独设过固定像素字号，它们可能不会跟随整篇缩放；这是飞书行内样式优先导致的。
- 行高会随字号统一调整为 1.6，标题的行高比例可能与飞书默认略有差异。
- 若浏览器不支持 `color-mix()`，面板边框等细节会降级，但核心功能不受影响。

测试覆盖：

- 单段选区精确包裹、字号/字体生效；
- 跨段落选区、文字不丢失；
- 整篇缩放时正文 20px、二级标题 27.5px、标题 42.5px；
